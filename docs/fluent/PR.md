# Add scoped Fluent windows, components and persistence

WindUI currently shares window/configuration/signal state across instances. Closing a window can affect other UI, and multi-window state has no separate owner. This change introduces scoped contexts while retaining the existing facade and function declarations, then adds the approved Fluent themes, layouts, components, navigation, notification and persistence features.

Classic/Premium/Glass are opt-in. Existing theme names and entrypoints remain. Window1 without an explicit ID retains the legacy config path; explicit/multiple windows get independent namespaces. Close remains reversible and keeps Close():Destroy(). Exit from the KeySystem now aborts the pending CreateWindow with nil and a cancellation reason instead of waiting forever; key acceptance rules and provider verification implementations remain intact.

The distribution is generated by DarkLua. Main CI no longer commits/pushes generated output, PR CI fails on build/test errors, and artifacts include a native Roblox gallery place.
